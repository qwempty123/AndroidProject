# CourseMarket

CourseMarket is a Kotlin + Android Views demo marketplace for online courses.

## Included
- Home screen with featured courses and category shortcuts
- Course catalog with text search and category filtering
- Course detail dialogs
- Favorites
- Shopping cart with total calculation
- Demo checkout that moves courses into the purchased list
- Profile and purchased courses
- Local persistence using SharedPreferences

## Run
1. Open the project in Android Studio.
2. Sync Gradle.
3. Select the `app` run configuration and an emulator or connected Android device.
4. Press **Run**.

## Important
This is a functional local prototype. Course data is bundled in the app. Checkout is a demo flow only: no payment provider, remote backend, real user accounts, or cloud synchronization is connected.
