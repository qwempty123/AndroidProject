# Руководство администратора CourseMarket

## 1. Вход

Используйте демонстрационную учётную запись:
- Логин: `admin`
- Пароль: `admin123`

После входа откройте «Профиль» и выберите «Панель администратора».

Для реального развёртывания пароль по умолчанию необходимо сменить; в текущем прототипе нет пользовательского интерфейса смены пароля.

## 2. Управление каталогом

В разделе «Управление курсами» доступны операции:
- **Добавить курс:** название, преподаватель, описание, категория и цена. Новый курс записывается в SQLite и получает учебную структуру из базовых модулей.
- **Изменить курс:** можно изменить название, преподавателя, описание и цену.
- **Удалить курс:** запись удаляется только если это не нарушает ссылочную целостность. Если курс присутствует в истории заказов, SQLite блокирует удаление через внешний ключ.

## 3. Управление заказами

В разделе «Заказы клиентов» отображаются номер заказа, пользователь, покупатель, email, сумма, способ и текущий статус.

Доступные действия:
- Подтвердить (демо) — статус `CONFIRMED_DEMO`.
- Отменить — статус `CANCELLED`.
- Отклонить — статус `REJECTED`.

Изменение статуса не вызывает реальный возврат и не влияет на банковские счета. При статусе CANCELLED/REJECTED курс исключается из списка активных покупок.

## 4. Ограничения безопасности

- Администратор и клиенты хранятся в локальной SQLite.
- Пароли не сохраняются открытым текстом: используется PBKDF2-хеш с солью.
- Это не серверная система управления доступом: пользователь, имеющий доступ к файлам или root-доступ устройства, может исследовать локальную БД.
- Для реального магазина нужны серверная аутентификация, авторизация на сервере, аудит действий, резервное копирование и защищённое управление секретами.
