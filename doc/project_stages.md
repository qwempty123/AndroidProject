# Этапы разработки проекта

Методические материалы разбивают индивидуальный проект на шесть этапов.

## Этап 1. Инициализация и проектирование
- Создан публичный репозиторий AndroidProject.
- Зафиксированы предметная область, роли и основные сценарии.
- Описаны SQLite-таблицы, связи и ограничения.
- Android `.gitignore` присутствует в корне.

## Этап 2. Разработка UI
- Реализованы главная, каталог, карточки деталей, корзина, профиль, обучение и админ-панель.
- Для каталога используется RecyclerView с CourseAdapter/ViewHolder.
- Главная навигация использует BottomNavigationView.
- Экраны размещаются через Fragment host на ConstraintLayout.
- Цвета, размеры и строки выносятся в resources; предусмотрены values и values-night.

## Этап 3. Интеграция базы данных
- Реализован SQLiteOpenHelper.
- Созданы таблицы категорий, пользователей, курсов, уроков, избранного, корзины, заказов, позиций заказа и прогресса.
- Добавлены внешние ключи, индексы, ограничения и схема версионирования.

## Этап 4. Бизнес-логика
- SQL-запросы вынесены в CourseMarketRepository.
- Методы репозитория используют Dispatchers.IO.
- Реализованы регистрация/вход, каталог, избранное, корзина, checkout, уроки, прогресс и администрирование.

## Этап 5. Тестирование
- Добавлены unit-тесты учебной базы.
- Добавлены instrumented tests репозитория и SQLite.
- Создан GitHub Actions workflow: unit tests, assembleDebug и сохранение APK artifact.
- Перед сдачей необходимо пройти ручные тест-кейсы, включая поворот экрана и пустые поля.

## Этап 6. Защита проекта
- README, руководство пользователя и администратора, анализ предметной области, схема БД и план тестирования размещены в doc/.
- Debug APK создаётся через `assembleDebug`.
- После успешного CI-запуска APK публикуется как artifact, который можно скачать на другом компьютере.
- Для финальной защиты рекомендуется добавить скриншоты реального приложения в README и приложить полученный APK.
