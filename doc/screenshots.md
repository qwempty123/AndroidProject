# Скриншоты для отчёта

Методичка требует README с описанием и скриншотами. В текущем репозитории автоматического снимка работающего эмулятора пока нет.

После успешной сборки сделай настоящие скриншоты приложения:
1. Экран авторизации.
2. Главная и каталог с RecyclerView.
3. Детали курса и содержание урока.
4. Корзина и форма демонстрационного заказа.
5. Профиль с прогрессом.
6. Панель администратора.

Сохрани PNG в папку `screenshots/` и добавь в README, например:
`![Каталог курсов](screenshots/catalog.png)`

Используй реальные снимки текущей сборки, а не макеты или изображения, которые не соответствуют приложению.
