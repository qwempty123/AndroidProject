# План тестирования CourseMarket

## 1. Среда

- Android 7.0 или новее (minSdk 24).
- Android Studio и Android SDK для сборки.
- SQLite на устройстве.
- Доступ к тестовой базе приложения; для каждого теста с созданием схемы использовать чистую базу.

## 2. Функциональные тест-кейсы

| ID | Название | Предусловие | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| TC-01 | Регистрация пользователя | Приложение запущено, экран входа | Ввести логин и пароль, нажать «Создать аккаунт» | Создана запись users с ролью CLIENT, открыта главная |
| TC-02 | Валидация пустых полей | Открыт экран регистрации/входа | Оставить логин или пароль пустым и подтвердить | Появляется сообщение об ошибке, приложение не падает, запись не создаётся |
| TC-03 | Добавление курса администратором | Выполнен вход admin | Открыть панель, добавить курс с заполненными полями | В SQLite появляется courses запись, карточка отображается в RecyclerView |
| TC-04 | Сохранение состояния при повороте | Открыт каталог или урок | Ввести поисковый запрос/открыть урок, повернуть устройство | Экран перестраивается; поиск/категория/сортировка или открытый урок восстанавливаются |
| TC-05 | Удаление курса | Вход администратора, курс без заказов | Нажать «Удалить» и подтвердить | Курс исчезает из RecyclerView; связанные уроки удалены каскадно |
| TC-06 | Защита истории заказов | Существует заказ с позицией курса | Попытаться удалить этот курс | Операция блокируется внешним ключом, данные заказа сохраняются |
| TC-07 | Создание демонстрационного заказа | Клиент авторизован, корзина не пуста | Указать имя/email, выбрать метод оплаты, принять условие | Созданы orders и order_items в транзакции; корзина очищена; деньги не списываются |
| TC-08 | Сохранение прогресса | Клиент приобрёл курс | Пройти тест и завершить урок; перезапустить приложение | lesson_progress содержит отметку, курс показывает обновлённый процент |
| TC-09 | Изменение статуса заказа | Выполнен вход admin, заказ существует | Подтвердить/отменить/отклонить заказ | orders.status изменён; профиль отображает актуальный статус |
| TC-10 | Проверка внешних ключей | Создана SQLite-база | Выполнить PRAGMA foreign_keys и попытаться создать ссылку на отсутствующий объект | Foreign keys включены; некорректная связь отклоняется SQLite |

## 3. Автоматические тесты

- `CourseLearningContentTest` проверяет наличие 61 урока и обязательных полей учебных материалов.
- `CourseMarketDatabaseTest` проверяет регистрацию/вход, избранное, корзину, оформление заказа, прогресс и структуру таблиц с внешними ключами.

## 4. Команды запуска

Windows:
```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

Instrumented tests (на подключённом устройстве или эмуляторе):
```powershell
.\gradlew.bat connectedDebugAndroidTest
```
